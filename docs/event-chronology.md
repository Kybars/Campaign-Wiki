# Event chronology

Event chronology is composed after the Player/DM read model has filtered entities and facts. It never reveals hidden rows, counts, anchors, or relationships.

Only ISO-like exact dates are sorted as dates. Explicit numeric sequence is sorted within its own group. Source-provided era/context creates a group but does not imply ordering inside it. Fictional-calendar dates and relative timing retain their source text in a neutral `Recorded timing` group, while absent chronology belongs to `Unknown date`. Incomparable entries use name then canonical ID only as a deterministic display fallback, not a historical claim.
